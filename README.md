# Hyland OnBase Administrator Solutions

A collection of SQL scripts and Windows PowerShell solutions for Hyland OnBase administrators.

## Contents

- **SQL** — Queries and scripts for administering and troubleshooting OnBase databases
- **PowerShell** — Automation and administration scripts for Windows environments

> Update this section as solutions are added to the repository.

## Requirements

- An environment with Hyland OnBase access
- Appropriate database and system administrator permissions
- SQL Server tools or management software
- Windows PowerShell

Review each script before running it. Back up your database and test changes in a non-production environment.

## Usage

1. Clone this repository:

   ```powershell
   git clone https://github.com/runlevel-4/Hyland-OnBase-Administrator-Solutions.git
   ```

2. Review the script documentation and configuration options.
3. Run SQL scripts using your preferred SQL client.
4. Run PowerShell scripts from an elevated PowerShell prompt only when required.
